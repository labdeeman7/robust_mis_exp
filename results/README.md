# Compact experiment results

This directory contains small, version-controlled result summaries only. Large generated artifacts—including prediction masks, galleries, and per-instance tables—remain under the ignored `outputs/` tree and can be regenerated from the documented scripts.

- `c6_sam1_vit_h_pilot_summary.json`: aggregated P1–P7 pilot metrics overall and by bucket.
- `c6_sam1_vit_h_pilot_run_metadata.json`: model, GPU, framework, and evaluated sample counts.
